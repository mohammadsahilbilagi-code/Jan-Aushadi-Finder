# Jan-Aushadi-Finder

A Jan Aushadi Finder is an application or website that helps users locate nearby Pradhan Mantri Bhartiya Janaushadhi Kendras (PMBJK), where affordable generic medicines are sold under the Government of India’s healthcare initiative.

Main Purpose

The app/system helps people:

Find nearby Jan Aushadi medical stores
Search medicines and their prices
Compare branded medicines with generic alternatives
Check medicine availability
View store location, contact details, and timings
Key Features
📍 Store Locator using GPS/maps
💊 Medicine Search
🔍 Generic Medicine Information
📦 Availability Tracking
📞 Contact & Directions
❤️ Affordable Healthcare Support
Technologies Commonly Used
Frontend: Android (Kotlin / Jetpack Compose)
Backend: Firebase / Node.js
Database: Firestore / MySQL
Maps: Google Maps API
Authentication: Firebase Auth
Benefits
Reduces medicine costs for patients
Improves healthcare accessibility
Promotes awareness of generic medicines
Supports digital healthcare solutions in India

This type of project is useful as an Android mini-project or healthcare service application.
Related initiative: Pradhan Mantri Bhartiya Janaushadhi Pariyojana
